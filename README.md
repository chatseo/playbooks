# ChatSEO Playbooks

Free, ungated SEO playbooks from [ChatSEO](https://link.chatseo.app/pb-seo-system).

- [L'audit du consultant SEO, en une conversation](https://chatseo.github.io/playbooks/seo-consultant-audit-system-fr/) : version française.
- [The SEO Consultant's Audit, in One Chat](https://chatseo.github.io/playbooks/seo-consultant-audit-system/): rank tracker, keyword tool, backlink tool, crawler, Search Console, run in one conversation instead of five tools, and sent to the client under your own name.
- [L'abonnement SEO du web designer](https://chatseo.github.io/playbooks/web-designer-seo-retainer-fr/) — version française.
- [The Web Designer's SEO Retainer](https://chatseo.github.io/playbooks/web-designer-seo-retainer/) — every site you've built is a client who already trusts you: the system for reopening them and selling monthly SEO retainers.
- [Claude Runs Your SEO](https://chatseo.github.io/playbooks/claude-runs-your-seo/) — connect Claude to your Search Console and your CMS: the 7 jobs, from finding the quick win to shipping and verifying the fix.
- [The Claude SEO System](https://chatseo.github.io/playbooks/claude-seo-system/) — find the pages Google already wants to rank, fix them, recheck on autopilot.
- [The Claude SEO Department](https://chatseo.github.io/playbooks/claude-seo-department/) — six SEO functions, one shared brief.
