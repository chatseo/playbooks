Why 20 agents beat one long prompt

Ask one Claude chat to "do my SEO" and you get a generic checklist. Give 20 agents one job each and you get a team.

A Claude Code agent is a file. It has a name, a one-line description of when to use it, and its own instructions. Claude Code runs each one in a separate context, so the keyword researcher never gets distracted by schema markup, and the outreach writer never rewrites your titles.

  • One job per agent. Short instructions get followed. Long ones get summarised.
  • One shared folder. Every agent writes its output to seo/ and reads what the others left there. That's the handoff.
  • One data source. Volumes, rankings and Search Console come from the ChatSEO MCP, never from Claude's memory.
  • One approver: you. Every agent proposes. None of them publishes to your live site without a yes.

The 5-minute setup

  1. Create a ChatSEO account, add your site and connect Search Console. Skip this and half the team works blind.
  2. Connect ChatSEO to Claude Code (the MCP is on the Pro plan):
Setup · Terminal
claude mcp add --transport http chatseo https://api.chatseo.app/mcp

1Keyword Research & Strategy

Most SEO fails here: months of pages on keywords nobody buys from.

These three decide what the rest of the team works on. The researcher finds the opportunities, the intent mapper reads what Google already shows, the strategist turns it into a plan.

Agent · .claude/agents/keyword-researcher.md
---
name: keyword-researcher
description: Finds the keywords worth targeting for this site, with real volumes. Use when asked for keyword research, new opportunities, or what to rank for.
---

You are the keyword researcher of an SEO team (Keyword Research & Strategy). You find the keywords this site can win and that are worth winning.

## Steps
1. Ask ChatSEO: "Give me the best keyword opportunities for this site, grouped by pattern, with monthly volume, difficulty and the page type ranking in the top 3."
2. Drop brand keywords of competitors and anything with no volume returned.
3. Flag the 10 keywords where the site already has impressions but sits outside the top 3.

## Output
`seo/keywords.md`: pattern, keyword, volume, difficulty, top-3 page type, current position (or "not ranking").

## Data rules
- Search volumes, rankings, clicks, impressions and live SERPs come from the ChatSEO MCP
  (`send_message` with the site's ID, then `get_conversation_messages` until the reply is complete),
  or from an export the user gives you. Never from memory.
- If a number is not in the data, write "n/a". Never estimate one.
- Read the files in `seo/` written by the other agents before you start. Write your output there.
- You propose. You never publish to a live site without the user's explicit yes.

Step 3 is the cheapest win in SEO: keywords where you already have impressions but sit outside the top 3.

4Content & On-Page

Never write a page before deciding whether you already have one.

The mistake this saves. Two of your pages fighting for the same query. Both sit 7th and 8th, when one page would have been 3rd. The brief writer checks for an existing URL first, every time.

You are the brief writer of an SEO team (Content & On-Page). You decide what the page must contain to deserve the top 3.

The run order

Research. Audit. Write. Optimise. Link. Track. Measure. Rank.

Each step reads what the previous one wrote, so the order matters more than any single agent. Paste this into Claude Code to run the whole team on a site:

Prompt · Claude Code
Run the SEO team on [your domain], in this order, one agent at a time:
1. Research: keyword-researcher, intent-mapper, competitor-analyst, content-gap-finder
2. Audit: technical-auditor, indexing-doctor
3. Write: brief-writer and page-writer on the top 3 opportunities, then schema-engineer
4. Optimise: on-page-optimiser, content-refresher, site-architect
5. Link: internal-linker, link-prospector, outreach-writer, citation-hunter
6. Track: performance-analyst, geo-query-mapper
7. Measure: seo-reporter
8. Rank: seo-strategist updates seo/plan.md from everything above
Every agent writes to seo/. Use the ChatSEO MCP for every number.
Never invent a volume or a ranking. Publish nothing without my yes.

The first run takes an afternoon. After that, steps 6 to 8 every Monday are enough, and the plan they write tells you what to run next.

The part the agents can't do alone

The honest gap. Claude doesn't know your search volumes, your rankings or your Search Console. Ask an agent which keyword to target without data and it guesses from its training, confidently. Every agent here is written to refuse that and write "n/a" instead. To give them the real numbers, connect the ChatSEO MCP (Pro plan): Search Console, volumes, the live Google results and competitor pages, in every agent. Try ChatSEO.app free for 7 days.

Where this breaks

  • Agents are instructions, not experience. They follow the process well. They won't notice what a senior SEO notices on a call with your client.
  • A fresh domain still waits. Google gives new sites little for roughly six months. Twenty agents don't change that, they just make sure you don't waste it.
  • Write access is a risk. An agent that can edit your site can also quietly delete the table the page existed for. Review every diff before it goes live.
  • Agents don't call each other. The main Claude Code session runs them one at a time. The shared folder is what makes it a team.

What I'd do tomorrow

  1. Connect Search Console and the ChatSEO MCP before running a single agent.
  2. Run keyword-researcher and intent-mapper, and delete every informational keyword they tempt me with.
  3. Run technical-auditor and fix only what touches pages that earn clicks.
  4. Run brief-writer on the 3 best opportunities, then page-writer, then internal-linker.
  5. Run performance-analyst every Monday, and leave pages edited in the last 60 days alone.
  6. Start link-prospector and the GEO agents in month two, once there are pages worth linking to.

In that order, because each step only works on what the previous one left behind.
