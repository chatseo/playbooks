# The Complete Claude SEO Playbook: 200 resources

Playbook: https://chatseo.github.io/playbooks/complete-claude-seo-playbook/

playbooks/   50 step-by-step methods, one job each. Read one, run it with Claude and your data.
skills/      50 Claude skills, one folder each. Save as .claude/skills/<name>/SKILL.md
             (Claude Code) or zip a folder and upload it as a skill (Claude.ai).
prompts/     50 paste-in prompts. Copy the fenced block, paste it above your export.
workflows/   25 routines that chain the skills on a cadence, with hand-offs written out.
templates/   25 fill-in documents: briefs, reports, logs, maps, checklists.

Every prompt and skill ends on one action. Every one refuses to invent a number it
was not given. Keep both rules when you edit them.

Claude cannot see your Search Console on its own. Connect it, or paste the export it
asks for. The connection I use: https://link.chatseo.app/pb-complete-claude-seo-playbook
