# Find the gap behind the map pack

**Area:** Local SEO

**When.** Paste this with your profile data and the three businesses in the pack when you want to know which gaps are closable.

## Prompt

```
Below are: my Google Business Profile data (primary category, review count, rating, photo count, website URL, distance from the searched point if known), the same fields for the 3 map pack businesses for my main keyword, and the keyword and location searched. If the competitor rows are missing, ask me for them before doing anything.

Compare field by field: category match to the keyword, review count and rating, review recency if given, photo count, whether the landing page title names the service and city, and whether my address sits inside the searched area. Rank gaps by distance behind (a competitor with 3 times my reviews is a bigger gap than 2 more photos). Mark gaps I cannot close (distance, a category I cannot claim) so I stop chasing them.

Output a table, max 8 rows, columns: factor, me, competitor 1, competitor 2, competitor 3, gap size (large, medium, none), closable (yes or no), what to do. If a number is not in the data I gave you, write "cannot compute from this data". Never estimate.

Finish with one action: the single closable gap to work on first, no alternatives.
```
