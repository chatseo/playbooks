# Write the monthly organic report

**Area:** Google Search Console analysis

**When.** Paste this on the first of the month with the totals and top lists when someone needs the story in two minutes.

## Prompt

```
Below are: my Search Console totals for this month, last month and the same month last year (clicks, impressions, CTR, position), this month's top 20 pages and queries with comparison columns, and GA4 organic conversions if I have them. If the comparison columns are missing, ask me for them before doing anything.

Write the report for someone who reads it in 2 minutes. Compare month over month and year over year; say which matters more this month (seasonality shows year over year). Name the 3 pages gaining the most clicks and the 3 losing the most, with position change. Name new queries with at least 200 impressions. Do not explain a change with a cause the data does not show; write "unknown, needs a look".

Output fixed sections: Headline (one sentence, the click change), Numbers table (metric, this month, last month, last year, change), Winners (max 3), Losers (max 3), New queries (max 5), Next month. If a number is not in the data I gave you, write "cannot compute from this data". Never estimate.

Finish with one action under Next month: the single thing to do, no alternatives.
```
