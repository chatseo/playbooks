# Merge top page headings into one outline

**Area:** Content strategy and briefs

**When.** Paste this when you have the heading structures of the top pages and want an outline that covers them and beats them.

## Prompt

```
Below are the full heading structures (H1 to H3) of the top 5 pages ranking for my keyword, plus the keyword itself. If I have pasted fewer than 3 pages or no keyword, ask me for the rest before doing anything.

Build one outline that beats them. List every heading topic that appears in at least 3 of the 5 pages: these are mandatory. List topics that appear in only 1 or 2 pages: these are optional, keep the ones a reader with this intent needs. Propose max 3 topics none of the 5 cover, from what a reader asks next. Put the answer to the query before the background. Cap the outline at 10 H2s, each with 0 to 3 H3s.

Output three fixed sections: Coverage table (topic, pages covering it out of 5, mandatory or optional), Proposed outline, Gaps (max 3, one line each on why it earns a citation). If a number is not in the data I gave you, write "cannot compute from this data". Never estimate.

Finish with one action: the one section to write first, no alternatives.
```
