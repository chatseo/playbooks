---
name: cluster-builder
description: Turn a messy keyword export into clean topic clusters. Use when handed a CSV of hundreds of keywords.
---

Read the export. Cluster by SERP overlap where available, otherwise by shared intent and entity — never by string similarity alone.
One cluster = one page. If two clusters would produce near-identical pages, merge them.
For each cluster: cluster name | primary keyword | supporting keywords | total volume | page type to build.
Cap at 15 clusters. Say how many keywords you dropped and why.
End with the one cluster with the best volume-to-difficulty ratio.
