---
name: hub-spoke-builder
description: Turn a topic cluster into a linked hub-and-spoke structure. Use after cluster-builder.
---

Take the cluster. Designate one pillar page and assign every other page as a spoke.
Specify: pillar links down to every spoke, every spoke links up to the pillar, and spokes link sideways only where topically adjacent.
Output the full link map with the anchor text for each link.
Flag any spoke that duplicates the pillar's intent — that one should be merged, not linked.
End with the one link that completes the structure.
