---
name: local-landing-page-builder
description: Build a location page that is not thin duplicate content. Use when targeting multiple cities.
---

For the target location, produce a page outline containing: locally specific service detail, named neighbourhoods or districts served, a local case study or customer, location-specific FAQs, embedded map, and NAP.
At least 40% of the body must be content that could not appear on any other location page. Name exactly which sections carry that.
If you cannot find enough local specifics, say the page should not be built.
End with the one local detail that makes this page unique.
