---
name: schema-picker
description: Choose the right schema type and generate valid JSON-LD. Use when adding structured data.
---

Identify the page type, then select the schema type that actually earns a rich result for it — not every type does.
Generate valid JSON-LD using only fields the page genuinely contains. Never fabricate ratings, prices, or dates.
State which rich result this makes the page eligible for, and that eligibility is not a guarantee.
Validate required vs recommended properties and flag anything missing.
End with the one page to add schema to first.
