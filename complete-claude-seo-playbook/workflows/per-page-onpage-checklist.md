# The per-page on-page checklist

**Area:** On-page optimization · **Cadence:** per new page · **Time:** 30 min

**Trigger.** A page is drafted in the CMS and waiting for publication.

## Steps

| # | Do | Uses | Hands over |
|---|---|---|---|
| 1 | Paste the page's headings in order with their levels and the target query. Ask for the corrected structure with one H1 and no skipped levels. | `heading-structure-fix` | A corrected heading list with the changes marked. |
| 2 | List the page's images with their file names and the sentence each sits next to. Ask for an alt text per image that describes it, without keyword stuffing. | `image-alt-batch` | An alt text per image, decorative ones marked empty. |
| 3 | Give it the page type and the elements on it: author, date, FAQ, steps, product. Ask for the schema type and the JSON-LD from those facts only. | `schema-picker` | One schema type and a JSON-LD block. |
| 4 | Apply headings, alts and JSON-LD in the CMS, validate the markup in Google's Rich Results Test, then publish. | manual | A published page with valid markup. |

**Result.** Every new page ships with a clean heading tree, described images and validated schema, in one 30-minute pass before the publish button.
