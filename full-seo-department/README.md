# The Full Claude SEO Department — 50 agents, 50 skills

Playbook: https://chatseo.github.io/playbooks/full-seo-department/

agents/   50 system prompts, one file each. Save as .claude/agents/<name>.md
          in a project (Claude Code), or paste one as a Project's instructions
          (Claude.ai). Each agent runs exactly one skill.
skills/   50 skills, one folder each. Save as .claude/skills/<name>/SKILL.md
          (Claude Code) or zip a folder and upload it as a skill (Claude.ai).

Every agent and every skill ends on one action. Every one refuses to invent
a number it was not given. Keep both rules when you edit them.

Agents cannot see your Search Console on their own. Connect it, or paste the
export they ask for. The connection I use: https://link.chatseo.app/pb-full-seo-department
