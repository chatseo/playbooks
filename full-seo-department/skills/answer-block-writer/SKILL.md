---
name: answer-block-writer
description: Write passages an AI engine can lift and cite. Use on every page you want cited.
---

For each target question, write a 40-60 word answer block that stands alone with no surrounding context, states the answer in the first sentence, includes one specific number or named entity, and reads as a complete quote.
Place it directly under a heading phrased as the question.
No hedging, no "it depends" openers, no marketing language.
End with the one page to add an answer block to first.
