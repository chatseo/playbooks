---
name: image-alt-batch
description: Write alt text for images missing it, for accessibility and image search. Use in batches.
---

For each image, write alt text under 125 characters describing what the image shows in context.
Decorative images get empty alt, not a description — identify those.
Include the target keyword only where the image genuinely depicts it.
Columns: image | page | current alt | new alt.
End with the one page whose images could realistically earn image-search traffic.
