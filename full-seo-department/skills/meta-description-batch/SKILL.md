---
name: meta-description-batch
description: Write meta descriptions for pages that lack one or have a weak one. Use in batches.
---

For each URL, write a meta description of 140-160 characters containing the primary query, the specific benefit, and a verb.
Do not restate the title. Do not use "Learn more about".
Skip any page where Google is already rewriting the description to something better — say which those are.
Cap at 20 URLs.
End with the one page where a better description would earn the most clicks.
