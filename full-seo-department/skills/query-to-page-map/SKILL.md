---
name: query-to-page-map
description: Map which page Google actually serves for each of your target queries. Use to catch mismatches.
---

For each target query, pull the URL GSC reports as ranking.
Compare it to the URL you intended to rank. Flag every mismatch.
Columns: query | intended URL | actual URL | position | why Google chose differently.
A mismatch usually means intent or internal linking, not keyword density.
End with the one query where the wrong page is ranking and it matters most.
